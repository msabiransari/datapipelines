The Claude Code MCP server config

claude mcp add --transport http datapipelines https://your-host/mcp \
  --header "DP-API-Key: dpk_<id>.<secret>"

The Cursor MCP server config: ~/.cursor/mcp.json

{
  "mcpServers": {
    "datapipelines": {
      "url": "https://your-host/mcp",
      "headers": { "DP-API-Key": "dpk_<id>.<secret>" }
    }
  }
}

The GitHub Copilot MCP server config: .vscode/mcp.json

{
  "servers": {
    "datapipelines": {
      "type": "http",
      "url": "https://your-host/mcp",
      "headers": { "DP-API-Key": "dpk_<id>.<secret>" }
    }
  }
}
