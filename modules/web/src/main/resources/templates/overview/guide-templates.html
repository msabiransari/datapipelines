Create with your agent

  1. Describe the query or transformation, the inputs it should accept and the dialect it targets.
  2. Ask a connected agent to build the template as a draft and render it with representative inputs.
  3. Open the draft it returns, read its description and rendered output, and try it with your own inputs. Someone allowed to release templates releases it from its workspace when it is ready.

Copying puts the text on your clipboard and nothing else: it sends no request and grants no access. Your agent works with the permissions of its own API key. Your role here does not author templates, so copy the request for a collaborator who can.

Templates hold reusable query or transformation logic that other resources can use. Parameters let the same logic answer different requests without duplicating it. For example, aggregate trips by zone for a selected period.

Related resources and help

A release keeps rendering the same SQL even while the template's next draft is being edited: a change is a new version, never a silent edit.
