Copying puts the text on your clipboard and nothing else: it sends no request and grants no access. Your agent works with the permissions of its own API key. Your role here does not author visualizations, so copy the request for a collaborator who can.

Visualizations define how data is presented, such as a chart, table or KPI. They include the input contract and rendering configuration so the presentation can be reused and tested. For example, show each borough's rideshare share in a comparison chart.

  1. Describe the question, the chart, table or KPI you want, and the input fields it should use.
  2. Ask a connected agent to build a draft visualization and test normal, empty and boundary fixtures in the renderer.
  3. Open the draft's Preview (test fixtures) tab, inspect its labels, units and empty states, and review the agent's test evidence. Someone allowed to release visualizations releases it from its workspace when it is ready.
  • Pipelines supply the source columns a visualization presents.
  • Dashboards reuse visualizations with sources whose columns match their input contracts.
