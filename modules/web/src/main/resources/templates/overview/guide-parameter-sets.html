Copying puts the text on your clipboard and nothing else: it sends no request and grants no access. Your agent works with the permissions of its own API key. Your role here does not author parameter sets, so copy the request for a collaborator who can.

Parameter sets define reusable inputs and how their values are evaluated together. They give related views consistent choices and dependent controls. For example, choose a year and then offer only the periods available within that year.

  1. Describe the inputs, their defaults and how one choice should narrow another.
  2. Ask a connected agent to build the parameter set as a draft and check it by evaluating representative choices.
  3. Open the draft it returns, read its controls and their dependencies, and try them with your own choices. Someone allowed to release parameter sets releases it from its workspace when it is ready.
  • Templates supply a control's choices when they come from data: a selector is a pinned template.
  • Dashboards pin a released parameter set, show its controls and pass the evaluated values to their source pipelines.

A set's controls can also be hard-coded choices; not every set needs a template.
