Copying puts the text on your clipboard and nothing else: it sends no request and grants no access. Your agent works with the permissions of its own API key. Your role here does not author pipelines, so copy the request for a collaborator who can.

Pipelines turn a data question into a repeatable workflow. They combine data sources, reusable templates and processing steps, accept parameters, and produce results you can inspect or use elsewhere. For example, compare rideshare share between two years and rank the largest changes.

  1. Describe the question, the data it should use and the inputs you want to vary.
  2. Ask a connected agent to build the pipeline as a draft and verify it against the source.
  3. Open the draft it returns, read its description and verification steps, and run it with your own inputs. Someone allowed to release pipelines releases it from its workspace when it is ready.

Templates hold the reusable query and transformation steps a pipeline pins; visualizations and dashboards present its results.

A common chain is pipelines, then visualizations, then dashboards; not every dashboard needs every link.
