Manage API keys
Your MCP key is in the top bar Signed in, you hold exactly one per workspace — copy it from the chip at the top right, or delete it there and sign in again to rotate. API keys for published endpoints are managed by a workspace admin at /api-keys/api-keys; the endpoints themselves are on /api-console.
