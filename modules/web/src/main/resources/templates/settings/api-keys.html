API keys

Keys are created and managed on the Keys page — MCP keys for your agents, endpoint keys for the programs that call published endpoints.

Manage API keys
Keys live on the Keys page Create an MCP key there with the role your agent needs and copy it when it appears — one time only, at creation; revoke it there and create another to rotate. Endpoint keys for published endpoints are managed by a workspace admin at /api-keys/api-keys; the endpoints themselves are on /api-console.
